## Claude Code extras
- `/task <request>` starts a task (writing-plans: Frame, then plan). `/grill <feature>` interviews you about the design first (grilling-designs, manual only). Plan with `/model opusplan` + plan mode (Shift+Tab): Opus plans, Sonnet executes.
- `/btw <question>`: quick side question about what is already in context; not added to history, no tools.
- Longer side discussion: `/branch <name>`, then `/resume <task-session>` to return; record outcomes with `nt decide`.
